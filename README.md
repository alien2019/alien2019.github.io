# 英语陪练（English Trainer）v1.0

中英互译默写练习小应用 · 适合小学生和成人英语学习 · 纯静态、零依赖、免运维。

## ✨ 功能

- **三种练习模式**：中译英（看中文默写英文）/ 英译中（看英文写中文）/ 听力朗读（听发音写英文），另有混合模式随机出题
- **自定义题库**：粘贴文本、上传 CSV/TXT/JSON、手动录入三种方式；多题库管理、搜索、去重
- **双判分模式**：智能宽松（忽略大小写/标点，容错 1 字母笔误）/ 严格逐字，按次练习可切换
- **多答案支持**：英文用 `a / an` 写法，任何一种都判对
- **成绩与错题本**：每轮结算得分 + 错题回顾
- **备份迁移**：一键导出/导入 JSON 题库，跨设备带走
- **外观可配**：名称、图标、主色调、朗读语音
- **响应式**：手机 / 平板 / 电脑自适应，支持深色模式

## 🚀 快速开始

**本地体验**：直接双击 `index.html` 用浏览器打开即可，无需安装任何东西。

**部署上线**：见 [docs/部署文档.md](docs/部署文档.md)，支持 Vercel / Cloudflare Pages / GitHub Pages / app.codebuddy.work，均为免费静态托管。

**访问入口**：
| 入口 | 地址 |
|---|---|
| 前端（练习） | `index.html` |
| 后台（题库管理） | `admin.html`（自动跳转至 `index.html#admin`） |

## 💾 数据说明

所有数据保存在**用户浏览器本地**（localStorage，key：`eng_trainer_v1`），
不联网上传、无需注册。换设备请使用后台「导出/导入 JSON 备份」迁移。
