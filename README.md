# 英语陪练（English Trainer）v2.0

中英互译默写练习小应用 · 适合小学生和成人英语学习 · **PWA 架构**、零依赖、免运维。

## ✨ 功能

### 练习核心（v1 保留）
- **三种练习模式**：中译英（看中文默写英文）/ 英译中（看英文写中文）/ 听力朗读（听发音写英文），另有混合模式随机出题
- **自定义题库**：粘贴文本、上传 CSV/TXT/JSON、手动录入三种方式；多题库管理、搜索、去重
- **双判分模式**：智能宽松（忽略大小写/标点，容错 1 字母笔误）/ 严格逐字，按次练习可切换
- **多答案支持**：英文用 `a / an` 写法，任何一种都判对
- **成绩与错题本**：每轮结算得分 + 错题回顾
- **备份迁移**：一键导出/导入 JSON，跨设备带走
- **外观可配**：名称、图标、主色调
- **响应式**：手机 / 平板 / 电脑自适应，支持深色模式

### 🆕 v2.0 新增
- **PWA**：手机/电脑可安装到桌面像原生 App；Service Worker 离线缓存，断网也能练；版本更新提示条
- **多成员档案**：「小朋友」「大人」独立档案，可增删；每人独立的规划/进度/积分/等级/徽章
- **学习规划**：每日目标题数、练习题库、题型、练习日（周几），首页「今日任务」进度环实时显示
- **激励机制**：答题积分（对+10/错+3/达标+50）、7 级成长等级、11 枚徽章、连续打卡 streak、达标撒花庆祝
- **语音交互**：自动朗读题目/答案/对错提示；语速、音调、重复次数、发音人可配；支持**麦克风语音作答**（Web Speech，不支持时自动隐藏）
- **数据升级**：v1 数据（题库/外观）自动迁移到 v2，无感升级

## 📲 安装（PWA）

| 平台 | 方法 |
|---|---|
| Android | Chrome 打开 → 页面内「📲 添加到主屏幕」按钮或浏览器菜单 |
| iOS / iPadOS | Safari 打开 → 分享 → 添加到主屏幕 |
| 桌面 | Chrome / Edge 地址栏右侧「安装」图标 |

安装后全屏运行，离线也能练习（首次需联网打开一次完成缓存）。

## 🚀 快速开始

**本地体验**：需通过 HTTP 访问（PWA 与 Service Worker 不支持 `file://`），例如：
```bash
cd english-trainer && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**部署上线**：见 [docs/部署文档.md](docs/部署文档.md)，支持 Vercel / Cloudflare Pages / GitHub Pages / app.codebuddy.work，均为免费静态托管。

**访问入口**：
| 入口 | 地址 |
|---|---|
| 前端（练习） | `index.html` |
| 后台（题库管理） | `admin.html`（自动跳转至 `index.html#admin`） |

## 💾 数据说明

- 所有数据保存在**用户浏览器本地**（localStorage，key：`eng_trainer_v2`），不联网上传、无需注册。
- **v1 老用户**自动迁移：题库与外观配置原样保留（原 `eng_trainer_v1` 数据不动）。
- 换设备请使用后台「导出全部数据 / 导入 JSON 备份」迁移（v2 备份含全部成员进度）。
