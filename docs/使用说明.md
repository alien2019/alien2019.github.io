# 英语陪练 · 使用说明（v2.0）

> 中英互译默写练习小应用 · 适合小学生和成人英语学习
> **v2 已升级为 PWA**：手机可「添加到主屏幕」像 App 一样使用，离线也能练；
> 支持多成员（大人/孩子各自规划、进度、激励）与语音交互。

---

## 一、这是什么

「英语陪练」是一个开箱即用的英语默写练习网页：

- **三种练习方式**：中译英（看中文默写英文）、英译中（看英文写中文）、听力朗读（听发音写英文），另有「混合模式」随机出题。
- **自带 3 个示例题库**：小学基础 20 句、日常口语 15 句、职场英语 15 句，打开即可练。
- **完全自定义**：老师/家长可自己导入题库（粘贴文本、上传 CSV/TXT/JSON）或逐条手动录入。
- **智能判分**：默认宽松模式（忽略大小写、标点、首尾空格，1 个字母的拼写笔误也算对），可一键切换「严格逐字」模式，适合成人应试。
- **即时反馈**：每题提交即判分，结束后有成绩单和错题回顾。

## 二、装到手机上（PWA 安装）

### Android（Chrome / Edge）
1. 用浏览器打开前端地址；
2. 首页会出现「📲 添加到主屏幕（像 App 一样用）」按钮，点击即可；若无按钮，用浏览器菜单里的「添加到主屏幕 / 安装应用」；
3. 桌面出现「英语陪练」图标，点开即全屏运行。

### iPhone / iPad（Safari）
1. 用 **Safari** 打开前端地址；
2. 点首页「📲 iOS 安装方法」按钮看图示，或直接：底部「分享」按钮 → 「添加到主屏幕」→ 添加；
3. 桌面出现图标，点开即全屏运行（需联网打开一次完成离线缓存）。

### 电脑（Chrome / Edge）
地址栏右侧出现「安装」图标时点击安装，即可获得独立窗口的桌面应用。

> 💡 应用更新后，页面顶部会出现「发现新版本」提示条，点「刷新更新」即可升级到最新版。

## 三、一家多人怎么用（成员与规划）

1. **切换成员**：点顶栏的成员胶囊（如「🧒 小朋友 ▾」），在弹出菜单中点选成员；也可在菜单里「＋ 添加成员」（依次输入名字、类型 1=小朋友/2=大人、头像 emoji、每日目标）。
2. **定学习规划**：进入「我的学习」→ 「学习规划」卡片，为**当前成员**设置每日目标（5~50 题）、练习题库、每日练习题型（中译英/英译中/听力至少一种）、练习日（周一~周日）→ 点「保存学习规划」。
3. **看完成进度**：首页「今日任务」卡实时显示 已练/目标 进度环和剩余题数；顶部成员菜单里也能看到每人当天进度。
4. **激励机制**：「我的学习」页有积分、等级（英语新芽 → 传奇学者共 7 级）、连续打卡（🔥 连续 N 天）、最近 14 天练习柱状图和 11 枚徽章墙。
   - 计分规则：答对 +10 分，答错 +3 分（鼓励坚持），完成每日目标 +50 分，连续打卡另有加成；
   - 达成每日目标或单轮全对时，页面撒花庆祝 + 语音表扬。

> 每个成员的数据完全独立：孩子和大人的进度、积分、规划互不影响。

## 四、怎么练（3 步开始）

1. 打开前端地址 → 在「1 · 选择题型」里点选 **中译英 / 英译中 / 听力朗读 / 混合模式**；
2. 在「2 · 选择题库」里选题库、题目数量（5/10/20/全部）和判分宽松度；
3. 点 **🚀 开始练习** → 逐题作答 → 提交后立即看到对错 → 练完看成绩和错题回顾。

> 💡 听力模式下会自动朗读英文，答题中可点「🔊 再听一遍」重复播放。
> 💡 输入框内按 **回车** 即可提交，比点按钮更快。
> 💡 答错的题结束时会进「错题回顾」，点「再练一遍」专门巩固错题。

## 五、语音怎么配（题库 → 语音设置）

进入「题库」→ 「语音设置」卡片：

| 设置项 | 作用 |
|---|---|
| 开启语音朗读 | 总开关，关掉后全站静音 |
| 出题后自动读题 | 进入题目自动朗读题干（听力模式建议开启） |
| 判分后读正确答案 / 判分后读对错提示 | 提交后的语音反馈 |
| 语速 / 音调 | 滑杆调节，小朋友建议语速 0.75~0.85 |
| 重复朗读次数 | 1~3 次（听力加强可选 3 次） |
| 朗读语音 | 自动（英语女声优先）或指定系统内的某个发音人 |
| 允许麦克风语音作答 | 开启后练习页出现「🎙️ 按住说话，松开识别」按钮，说出答案自动填入输入框（可再手动修改后提交） |

点「🔊 试听一下」可先试效果，再「保存语音设置」。

> ⚠️ 语音识别（麦克风）依赖浏览器 Web Speech 能力：**Chrome / Edge 支持**（需联网并允许麦克风权限）；不支持的浏览器会自动隐藏麦克风按钮，不影响其他功能。

## 五·二、不会做怎么办：提示功能 🆕

练习中遇到不会的题，点题目下方的 **「💡 给我点提示」**，提示会**循序渐进**地给，但**永远不直接给完整答案**：

| 第几次点 | 看到什么 | 例子（答案 apple） |
|---|---|---|
| 第 1 次 | 答案有多长 + 第一个字母/字 | `a____` |
| 第 2 次 | 再多揭示一部分 | `ap___` |
| 第 3 次 | 揭示大部分，仍留一点 | `appl_` |

- 提示上限（1~3 次）可在后台「提示设置」调整，用完按钮会变成「提示已用完」，实在不会可以点「跳过」看答案。
- **用过提示的题，积分按折扣计算**（默认 50%），避免一路点提示刷分；答对答错本身不受影响。可在后台关掉扣分，或改成 70%/30%。
- 开了语音朗读时，提示内容会被读出来，还不识字的小朋友也能用。
- 结算页会写明「其中 N 题用了提示」，错题回顾里也会标「💡 用了 N 次提示」，方便家长知道哪道题需要重点复习。

> 💡 建议：小学生用默认 3 次提示 + 50% 折扣；想更严格可设 1 次提示 + 30% 折扣。

## 六、多答案写法

英文答案支持多个可接受答案，用 `/` 分隔录入，练到任何一种都算对。

例：录入 `一个` → `a / an`，则答 `a` 或 `an` 均判对。

## 七、题库怎么管（老师/家长看这里）

点顶部「**题库**」进入管理页（也可直接访问后台地址）：

| 我想… | 操作 |
|---|---|
| 批量加题 | 「批量导入 → 粘贴文本」，每行一组：`中文\|英文`（逗号、制表符分隔也可），点「导入到当前题库」 |
| 用 Excel/CSV 导入 | 另存为 CSV 后「批量导入 → 上传文件」上传（第一列中文，第二列英文，首行表头会自动跳过） |
| 加一道题 | 「手动录入」填中文、英文，点「＋添加到题库」，回车可连续录入 |
| 新建题库 | 「＋新建题库」，如「三年级上册 Unit 1」 |
| 删题 | 题目列表点 ✕（支持搜索定位） |
| 换设备带走全部数据 | 「备份与迁移 → ⬇导出全部数据」（含题库 + 所有成员进度），在另一台设备「⬆导入 JSON 备份」 |
| 改主题 | 「外观设置」改名称、图标、主色调，点「保存设置」 |
| 调提示 | 「提示设置」开关提示按钮、设单题最多提示次数（1~3）、设用过提示后的积分折扣 |
| **改默认题库（新用户出厂题）** | 部署者直接编辑 `assets/js/banks.js` 配置文件（详见部署文档），只影响新用户首次打开 |

**改动即时生效**：后台保存后，回到练习页直接可用（同设备浏览器内）。

## 八、数据存在哪、会不会丢

- 数据保存在 **本机浏览器的 localStorage**（key：`eng_trainer_v2`），不联网、不上传、不注册账号，隐私安全。
- **同一设备同一浏览器**：刷新、关机重开都不丢；PWA 离线状态下答题，数据也存在本地。
- **换设备/换浏览器/清浏览器缓存会丢** → 请养成用「导出全部数据」定期备份 JSON 的习惯（v2 备份含全部成员进度），导入即可恢复。
- 想让学生共用同一份题库？把导出的 JSON 发给学生，学生在自己设备的「导入 JSON 备份」里导入即可。
- **v1 老用户**：首次打开 v2 会自动把旧题库与外观配置迁移到 v2（原 v1 数据保留不动），题库和设置不丢失。

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 听力题没有声音 | 确认设备未静音；iOS Safari 需先在页面上点过一次任意按钮（系统限制）；建议用 Chrome / Edge / Safari 最新版 |
| 朗读声音不好听 | 「语音设置 → 朗读语音」里换一个英语语音（列表来自系统，各设备不同） |
| 麦克风按钮不见了 | 当前浏览器不支持语音识别（如 iOS 微信内置浏览器），换 Chrome/Edge 即可；或检查「语音设置 → 允许麦克风语音作答」是否开启 |
| 点麦克风没反应 | 需允许浏览器使用麦克风（地址栏左侧锁图标 → 网站权限）；语音识别需联网 |
| 「添加到主屏幕」按钮没出现 | iOS 需用 Safari 的「分享 → 添加到主屏幕」；Android 需用 Chrome/Edge 访问 |
| 离线打不开 | 先联网正常打开一次，让 Service Worker 完成预缓存（首次约几秒） |
| 导入后没反应 | 检查每行是否有 `\|` 或逗号分隔；文件请用 UTF-8 编码 |
| 清了浏览器缓存数据没了 | 用之前的 JSON 备份导入恢复；没有备份则无法找回 |
| 页面打不开/白屏 | 确认访问的是正式部署地址；刷新或强刷（Ctrl/Cmd + Shift + R） |

## 十、适用浏览器

Chrome、Edge、Safari、Firefox 最新版，以及微信内置浏览器（iOS/Android）。
语音朗读与识别依赖浏览器 Web Speech 能力（Chrome/Edge 支持最完整），老旧浏览器（如 IE）不支持。
