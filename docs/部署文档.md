# 《英语陪练》部署与使用说明 v2.0

更新时间：2026-10-05　　维护人：（接手后请填写）

## 一、这是什么

一个面向小学生和成人英语学习的**中英互译默写练习**应用（v2.0 已升级为 **PWA**）。
支持自定义导入题库、中译英 / 英译中 / 听力朗读三种练习模式、智能宽松与严格双判分模式；
v2 新增：**PWA 安装与离线使用**、**多成员档案（独立规划/进度/积分/等级/徽章）**、**语音交互配置（朗读 + 麦克风语音作答）**。
**纯静态 HTML/CSS/JS，零依赖、零构建、无需数据库和服务器后端**，任何静态托管平台均可直接部署。

## 四、3 分钟上手：怎么改内容

1. 打开后台地址 → 「题库管理」
2. 导入（粘贴/CSV/JSON）或手动录入题目；「外观设置」可改名称、图标、主色调；「语音设置」可配朗读与语音作答
3. 点保存 → 回到练习页即生效
4. 改错了怎么办：「备份与迁移 → 恢复默认题库」可一键回到出厂的 3 个示例题库（⚠️ 会清空自定义内容，操作前建议先导出备份）

**数据存放位置**：浏览器 localStorage，key 为 `eng_trainer_v2`（首次打开自动迁移 v1 的 `eng_trainer_v1`，原 v1 数据保留不动）。
**备份方式**：后台「⬇导出全部数据」下载 JSON（含题库 + 全部成员进度）；恢复：同区域「⬆导入 JSON 备份」。

## 五、部署方式（三种任选，全部免费/静态托管）

### 前置准备
- [ ] 解压源码包
- [ ] 无需安装任何依赖、无需构建（纯静态）

> ⚠️ **PWA（安装到主屏幕 + 离线缓存）要求 HTTPS 或 localhost**。以下平台默认 HTTPS，均可正常使用 PWA。

### 方式 A：Vercel
1. 注册并登录 [vercel.com](https://vercel.com)
2. Import Project → 上传本目录（或先推到 GitHub 再导入）
3. Framework Preset 选 **Other / Static**，根目录保持默认
4. Deploy → 得到 `https://xxx.vercel.app`

### 方式 B：Cloudflare Pages（国内访问友好）
1. 登录 Cloudflare → Workers & Pages → Create → Pages
2. Upload assets → 把整个目录拖拽上传
3. 得到 `https://xxx.pages.dev`

### 方式 C：GitHub Pages
1. 新建 GitHub 仓库 → 上传本目录全部文件
2. Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)` → Save
4. 得到 `https://<用户名>.github.io/<仓库名>/`
5. 后台地址即为 `https://<用户名>.github.io/<仓库名>/admin.html`

### 方式 D：app.codebuddy.work（CodeBuddy 静态托管）
1. 在 CodeBuddy 工作区打开本项目
2. 使用「发布为应用」功能发布静态产物，得到公网访问地址

> ⚠️ **不要使用沙盒/预览环境作为最终交付地址**：沙盒会休眠，用户随时打开可能白屏。
> 部署完成后务必按「六、验收清单」逐项勾选。

## 六、验收清单（部署后逐项勾选）

- [ ] 浏览器直接打开前端地址，无控制台报错
- [ ] 四种练习模式（中译英/英译中/听力/混合）各练一轮走通，能出成绩和错题回顾
- [ ] 后台地址打开直达「题库管理」
- [ ] 粘贴 `测试|test` 并导入 → 回练习页能抽到该题
- [ ] 「导出全部数据」能下载 JSON；导入该 JSON 能恢复（含成员进度）
- [ ] 手机（竖屏）、平板、电脑三种宽度下无错位、无横向滚动
- [ ] 听力模式在目标设备上能出声
- [ ] 成员切换：小朋友答题后切到「大人」，今日进度独立归零
- [ ] 「我的学习」页：等级/打卡/徽章/趋势图/学习规划均正常渲染，规划保存后生效
- [ ] 语音设置：试听有声音，保存后刷新仍保留；支持麦克风的浏览器出现语音作答按钮
- [ ] **PWA**：地址栏有安装入口（或页面出现「添加到主屏幕」按钮）；安装后可离线打开练习

## 七、国内/海外都能稳定访问的建议

- 优先选择全球 CDN 的静态托管（Cloudflare Pages、Vercel）
- 本项目无任何外链资源（无 CDN 字体、无外部图片），不存在被墙风险
- 二维码/链接印刷或分发前，先在 Wi-Fi 与 4G 各打开一次验证

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开白屏 | 资源路径错误 / 沙盒休眠 | 确认 `assets/`、`manifest.json`、`sw.js`、`icons/` 与 index.html 同级完整上传；改用正式静态托管 |
| 后台改了前端没变 | 浏览器缓存 | 强刷 Ctrl/Cmd + Shift + R；SW 更新后点页面顶部「刷新更新」 |
| 没有安装按钮 | 非 HTTPS / 浏览器不支持 | PWA 需 HTTPS；iOS 用 Safari「分享→添加到主屏幕」 |
| 离线打不开 | SW 未完成预缓存 | 先联网正常打开一次再断网 |
| 麦克风作答不可用 | 浏览器不支持/未授权 | 用 Chrome/Edge 并允许麦克风权限；不支持的浏览器按钮自动隐藏 |

## 九、维护与交接

- **配置数据**：不在代码里，在用户浏览器 localStorage（key：`eng_trainer_v2`，自动兼容迁移 v1）
- **改样式**：`assets/css/style.css` 顶部 `:root` 变量（主色、圆角、阴影等）
- **改默认题库**：只改 `assets/js/banks.js`（结构见文件头注释：每个题库 `{ id, name, items:[{zh,en}] }`，英文多答案用 `/` 分隔）。**注意**：只影响新用户首次打开；老用户数据存在浏览器本地，需后台「导出/导入 JSON 备份」或「恢复默认题库」更新。改完后记得同步升级 `sw.js` 里的 `VERSION`，让已安装用户收到更新提示
- **改积分/等级/徽章规则**：`assets/js/store.js` 内 `POINTS` / `LEVELS` / `BADGES` 常量
- **改语音默认参数**：`assets/js/store.js` 内 `DEFAULT_CONFIG.speech`
- **改提示默认值**：`assets/js/store.js` 内 `DEFAULT_CONFIG.hint`（`enabled`/`maxLevel`/`deduct`/`deductRatio`）；提示的揭示算法在 `assets/js/hint.js`
- **发新版本**：改 `sw.js` 里的 `VERSION` 字符串（如 `eng-trainer-v2.0.1`），老用户打开页面会出现更新提示条
- **二次开发建议**：`store.js`（数据）与 `app.js`（界面）已分离，先改数据结构再改界面；两个文件均为 IIFE，各功能区以注释分节
